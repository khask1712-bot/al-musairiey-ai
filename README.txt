المصيريعي AI — نسخة أولية قابلة للنشر

ما الذي تفعله؟
- تعرض فهرس صفحات كتالوج المصيريعي المصور.
- تسمح باختيار صفحة/صورة منتج ثم سؤال المساعد عنها.
- الخادم يرسل صورة الصفحة مع سؤال العميل إلى OpenAI Responses API.
- يرد المساعد بلغة العميل، ويشرح ما تسمح الصورة باستنتاجه.
- يمنع تعليمات المساعد عرض الأسعار أو اختراع أرقام القطع أو توفر المخزون.
- يوجد رابط واتساب للشركة.

قبل التشغيل:
1) تحتاج مفتاح OpenAI API فعالاً مع رصيد/فوترة مناسبة.
2) لا تضع المفتاح في index.html أو ترسله في المحادثة.
3) محلياً: ثبت Node.js، ثم داخل مجلد المشروع نفذ:
   npm install
   ثم عيّن OPENAI_API_KEY كمتغير بيئة
   ثم npm start
4) افتح http://localhost:3000

النشر على Render:
1) ارفع هذا المجلد إلى GitHub كـ repository.
2) في Render اختر New > Blueprint أو Web Service واربط المستودع.
3) إذا استخدمت إعداد Web Service اليدوي:
   Build Command: npm install
   Start Command: npm start
4) في Environment أضف:
   OPENAI_API_KEY = مفتاح API الخاص بك (سري)
   OPENAI_MODEL = gpt-4.1-mini
5) اضغط Deploy وانتظر نجاح النشر.

ملاحظات مهمة:
- لم يتم إنشاء مفتاح API أو إدخاله أو تفعيل فوترة نيابة عنك.
- لم يتم نشر التطبيق بعد.
- أسماء بعض المنتجات أوصاف بصرية مبدئية من الصور، وليست تسميات فنية مؤكدة من نص الكتالوج.
- النموذج لا يعرف الأسعار أو المخزون، ولا يجب اعتباره تأكيداً لتوفر القطعة.
